# Ceo Advisor

Executive leadership guidance for strategic decision-making, organizational development, and stakeholder management. Includes strategy analyzer, financial scenario modeling, board governance frameworks, and investor relations playbooks. Use when planning strategy, preparing board presentations, managing investors, developing organizational culture, making executive decisions, or when user mentions CEO, strategic planning, board meetings, investor updates, organizational leadership, or executive strategy.

## Overview

This repository preserves the AITMPL skill definition and all companion resources published with it.

## Installation

```bash
git clone https://github.com/Brajesh31/claude-ceo-advisor-skill.git ~/.claude/skills/ceo-advisor
```

On Windows, use `%USERPROFILE%\.claude\skills\ceo-advisor` as the destination.

## Usage

Claude Code can load this skill when a request matches its description. Invoke directly with `/ceo-advisor` when needed.
